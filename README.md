# image-manager

Production-ready image microservice built with FastAPI, SQLAlchemy, Postgres, Celery, and S3/MinIO.

This is an initial scaffold. Dev, infra, models, and endpoints will follow in subsequent commits.

Quickstart (to be expanded later):

- Copy `.env.example` to `.env` and adjust as needed.
- Install Poetry 1.8+ and Python 3.12.
- Create and activate a virtualenv, then `poetry install`.
- Run API locally: `uvicorn app.main:app --reload`.
